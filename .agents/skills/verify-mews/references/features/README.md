# Feature map

The local app provides public and workspace shells with placeholders. The deployed infrastructure provides a health API. Storybook provides the separate component workspace. No rescue workflows are implemented.

- [Storybook](storybook.md): component stories, generated documentation, controls, and example interactions.
- [Application shell](app-shell.md): public and workspace routes, navigation, keyboard access, and fallback pages.
- App/API deployment checks are recorded in [the infrastructure guide](../../../../../docs/infrastructure.md).

As each feature works, add a focused file here describing its user-visible behavior, entry points, prerequisites, success and failure paths, and concrete verification steps. Keep this index in a useful order for checking the whole app.

Add documents when the corresponding behaviors exist; record agreed plans in [the roadmap](../../../../../docs/roadmap.md).
