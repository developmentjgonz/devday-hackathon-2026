# Overview

Overview shows personal open tasks, team open tasks, and reports waiting for review. The My tasks card expands the task list on the page. The Report reviews card opens Reports. Both cards have keyboard-accessible controls.

Completed task counts include all recorded completed tasks. They do not claim a time period because this database does not record when older tasks were completed. Due and overdue counts use America/New_York and exclude completed tasks.

The team chart groups completed tasks by their current assignee. The chart and thank-you message update when task status or assignment changes. Storybook uses isolated fictional records; production reads the workspace provider.
