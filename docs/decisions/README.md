# Decision records

Use a short record for a significant choice that future contributors may need to understand. Routine implementation details can stay with the code.

Name records `0001-short-topic.md`, increasing the number for each decision. Include the date, status, context, decision, and consequences. If a decision changes, preserve the original and link to its replacement.

There are no individual decision records yet. The current agreed direction is summarized in [architecture.md](../architecture.md).
